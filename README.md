# AURMOVA Blueprint OS

Josephine 私人使用的數字心理學諮詢工作台。第一版專注於清晰、可擴展的介面與資料邊界，**不包含任何自行推測的計算公式**。

## 第一版頁面

- **首頁 / 私人工作台**：工作摘要、快捷操作與五種諮詢項目入口。
- **建立顧客檔案**：姓名、性別、固定「日 / 月 / 年」生日欄位，以及諮詢項目選擇。
- **歷史顧客檔案**：本機檔案列表與諮詢工作區入口。
- **Josephine 私人諮詢區**：預留完整計算、內部分析及諮詢話術位置。
- **顧客簡版報告區**：與內部資料分離，僅提供人工確認後的顧客內容出口。

## 技術架構

無框架的 ES Modules 單頁應用：`index.html` 提供入口，`styles.css` 建立移動優先響應式設計，`src/app.js` 處理路由與互動，`src/data.js` 負責資料模型、驗證及顧客輸出的安全投影。第一版使用 `localStorage` 示範本機持久化；正式處理個人資料前，必須換成具身分驗證、權限控管及加密的後端。

## 本機預覽

```bash
npm start
```

瀏覽 `http://localhost:4173`。執行檢查：

```bash
npm test
npm run check
```

## 正式計算引擎接入點

在 `src/engine/` 建立獨立領域模組（目前刻意不建立假公式），輸入標準化的顧客資料並輸出 `internalAnalysis`。完整輸出只能交給私人工作區；顧客報告必須經由 `toCustomerReport()` 白名單投影和 Josephine 人工確認，禁止直接序列化内部分析对象。生产版同时应在服务端执行计算和权限检查，不能依赖前端隐藏。
